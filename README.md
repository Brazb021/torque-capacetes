# TORQUE Capacetes — vitrine 3D (portfólio)

Versão estática da loja de capacetes: coleção e visualizador 3D com rotação 360°.
Feita com Three.js (modelos GLB, pintura projetada por shader) e HTML/CSS puros.

A loja completa — Node.js + SQLite, cadastro, carrinho, estoque, Pix e cartão (Mercado Pago),
painel de administração com auditoria imutável e geração de capacetes 3D por fotos com IA local —
fica em um repositório privado.

Modelos 3D: "motorcycle helmet" de speed_show, "Motor Helmet" de VerbeeckTom, "Elementza Bike Helmet" de BaseOptimal — Sketchfab, licença CC BY 4.0.
